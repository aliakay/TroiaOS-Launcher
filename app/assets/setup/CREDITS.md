# Set Up credits

`hello.txt` is the word "hello" from the **Hershey Script** (simplex) font, joined into one path and smoothed by
[`tools/make_hello.py`](../../../tools/make_hello.py).

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the U. S. National Bureau of
  Standards.
- The format of the Font data in this distribution was originally created by
  James Hurt, Cognition, Inc., 900 Technology Park Drive, Billerica, MA 01821 (mit-eddie!ci-dandelion!hurt).

The glyphs were read from the `scripts.jhf` file of
[kamalmostafa/hershey-fonts](https://github.com/kamalmostafa/hershey-fonts) (its Hershey fonts licence: free for
any use with the acknowledgements above; not in the format distributed by the U.S. NTIS). The data file isn't kept
in this repository, only the path made from it.
